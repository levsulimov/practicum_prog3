## Описание проекта

Программа визуализирует полёт наблюдателя сквозь звёздное поле средствами библиотеки `tkinter`. Звёзды имеют разные размеры и цвета, движутся в трёхмерном пространстве относительно наблюдателя и увеличиваются при приближении. Пользователь регулирует скорость клавиатурой и меняет направление полёта мышью.

## Функциональные возможности

### Основной функционал

- Отображение 650 звёзд на чёрном фоне.
- Случайные начальные положения, размеры и цвета звёзд.
- Движение в 3D с перспективной проекцией на плоскость экрана.
- Увеличение видимого размера и яркости звёзд при приближении.
- Регулировка скорости клавиатурой от 0 до 2000 условных единиц в секунду.
- Изменение направления полёта движением мыши.

### Дополнительный функционал

- Плавное изменение направления движения.
- Автоматическое создание нового положения звезды после выхода за экран или приближения к наблюдателю.
- Адаптация изображения к размеру окна.
- Отображение текущей скорости и подсказок по управлению.
- Возврат направления к центру при выходе указателя за пределы поля.

## Требования к системе

- **Операционная система:** Windows, macOS или Linux с графическим рабочим столом.

## Принцип работы

### Модель и проекция

Класс `Star` хранит координаты `x`, `y`, `z`, базовый размер, цвет и идентификатор графического объекта. Класс `Starfield` создаёт окно и управляет всеми звёздами. Координата `z` определяет глубину относительно наблюдателя.

Положение звезды на экране вычисляется по формулам перспективной проекции:

```text
scale = focal / z
screen_x = width / 2 + x * scale
screen_y = height / 2 + y * scale
radius = min(12, max(0.5, size * scale))
```

Здесь `focal` — фокусное расстояние, `width` и `height` — размеры поля. При уменьшении глубины масштаб растёт, звезда удаляется от точки схода и увеличивается. Ограничение радиуса предотвращает появление слишком больших объектов.

### Анимационный цикл

Метод `animate()` изменяет координаты звёзд относительно движения камеры и обновляет объекты `Canvas`. Интервал до следующего обновления запрашивается через `after(16, ...)`; фактическая частота кадров зависит от компьютера и загрузки интерфейса. Для расчёта перемещения используется время между кадрами, ограниченное 0,05 секунды, чтобы после задержек не происходили резкие скачки.

## Возможные проблемы

### Ошибка `Cannot find a usable init.tcl`

Интерпретатор не может найти файлы Tcl/Tk. В Windows запустите установщик используемой версии Python, проверьте наличие компонента **Tcl/Tk and IDLE** и выполните восстановление установки. Затем повторите `py -3 -m tkinter`.

### Ошибка `No module named tkinter`

В выбранной установке Python отсутствует поддержка Tk. Установите её средствами своей ОС; например, в Ubuntu / Debian для системного Python используется пакет `python3-tk`. После установки снова выполните проверку `python3 -m tkinter`.

### IDE сообщает об отсутствии Python SDK

Укажите интерпретатор Python в настройках проекта и конфигурации запуска. Java SDK не подходит для запуска этого скрипта. Для запуска независимо от настроек IDE используйте терминал.

### Клавиши не меняют скорость

Активируйте окно программы и удерживайте стрелку вверх или вниз. Для буквенных клавиш включите английскую раскладку.
