## Описание проекта

Программа на `tkinter` отображает случайные разноцветные фейерверки: ракеты поднимаются с нижней границы окна и взрываются на разной высоте. Частицы разлетаются, оставляют короткие следы, постепенно затухают и исчезают по истечении времени жизни. Пользователь может создавать взрывы мышью и экспериментировать с гравитацией частиц с помощью слайдера.

## Функциональные возможности

### Основной функционал

- Автоматическая генерация ракет через случайные интервалы 0,35–0,85 секунды.
- Случайные места запуска и высота взрыва.
- Двенадцать вариантов цвета фейерверков.
- Создание 65–100 частиц при взрыве, если не достигнут общий лимит.
- Ограниченное время жизни ракеты: не более 3 секунд до взрыва.
- Время жизни каждой частицы: от 1,4 до 3 секунд после взрыва.
- Постепенное затухание и уменьшение частиц.
- Регулировка гравитации от −150 до 350 пикс./с², включая невесомость.

### Дополнительный функционал

- Взрыв в точке щелчка мышью.
- Короткие следы за частицами.
- Пауза и возобновление анимации.
- Сброс сцены и восстановление начальной гравитации.
- Счётчики активных ракет и частиц.
- Ограничение нагрузки: максимум 1800 частиц и 12 ракет одновременно.
- Изменяемый размер окна.

## Пример использования

1. Запустите `py -3 fireworks.py` в Windows или `python3 fireworks.py` в macOS / Linux.
2. Подождите несколько секунд: ракеты поднимутся и создадут разноцветные взрывы.
3. Щёлкните по свободному месту на небе, чтобы добавить собственный взрыв.
4. Установите гравитацию `0`: новые частицы будут разлетаться по прямым без вертикального ускорения.
5. Установите гравитацию `300`: траектории начнут заметно загибаться вниз.
6. Установите гравитацию `-150`: ускорение будет направлено вверх.
7. Нажмите `Пробел`, чтобы рассмотреть сцену, и повторно нажмите его для продолжения.
8. Нажмите «Сброс» для восстановления начальных параметров, затем `Esc` для выхода.

Изменение гравитации влияет на ускорение, а накопленная скорость сохраняется. Поэтому частица не обязана сразу полететь вверх при выборе отрицательного значения.

## Принцип работы

### Основные классы

- `Rocket` хранит положение ракеты, высоту взрыва, скорость, цвет, возраст и графический объект.
- `Particle` хранит координаты, скорость, время жизни, цвет, размер, прозрачность и короткую историю положений.
- `Fireworks` создаёт интерфейс, запускает ракеты, создаёт взрывы и обновляет сцену.

### Движение и гравитация

При взрыве частицы получают случайные направления и скорости от 45 до 220 пикселей в секунду. Для шага времени `dt` используются формулы:

```text
x = x + vx * dt
y = y + vy * dt + gravity * dt² / 2
vy = vy + gravity * dt
```

Ось `y` на экране направлена вниз: положительная гравитация притягивает частицы вниз, отрицательная — вверх. Ракеты поднимаются с постоянной скоростью; слайдер управляет именно частицами после взрыва.

### Время жизни и прозрачность

Ракета исчезает при взрыве. Каждая частица удаляется после окончания собственного времени жизни вместе с графическим следом. Таким образом, отдельный фейерверк существует конечное время, а общая анимация продолжается за счёт новых запусков.

У фигур `tkinter.Canvas` нет индивидуального альфа-канала. Эффект прозрачности реализован смешиванием цвета с чёрным фоном:

```text
remaining = 1 - age / lifetime
alpha = initial_opacity * remaining ** 1.4
display_channel = round(original_channel * alpha)
```

Это имитация прозрачности на однотонном фоне: при наложении частицы не выполняют полноценное альфа-смешивание друг с другом. След рисуется более тусклой линией по последним восьми положениям частицы.

### Анимационный цикл

Обновление запрашивается через `after(16, ...)`. Перемещение рассчитывается по времени между кадрами; шаг ограничен 0,05 секунды для защиты от резких скачков при задержках интерфейса. При сильных задержках симуляция замедляется. Частота кадров зависит от компьютера и количества объектов; лимит частиц ограничивает нагрузку.

## Возможные проблемы

### `Cannot find a usable init.tcl`

Python не находит файлы Tcl/Tk. В Windows запустите установщик используемой версии Python, проверьте компонент **Tcl/Tk and IDLE** и восстановите установку. После этого повторите `py -3 -m tkinter`.

### `No module named tkinter`

В выбранном Python отсутствует поддержка Tk. Установите её средствами ОС; например, для системного Python в Ubuntu / Debian используется пакет `python3-tk`. В Windows проверьте компонент Tcl/Tk установщика Python.

### IDE сообщает об отсутствии Python SDK

Выберите Python в настройках модуля и конфигурации запуска. До настройки IDE используйте запуск из терминала.

### Фейерверки не появляются

Проверьте, не включена ли пауза. Нажмите «Продолжить» или «Сброс» и подождите несколько секунд.
