# Практикум по программированию — лабораторные работы 3.1 и 3.2

Два самостоятельных проекта на Python с графической библиотекой `tkinter`.

| Работа | Описание | Документация |
| --- | --- | --- |
| 3.1 — Звёздное поле | Полёт сквозь звёзды с перспективой, управлением скоростью и направлением | [README](lab%203.1/README.md) |
| 3.2 — Фейерверки | Случайные цветные взрывы, затухание частиц и настройка гравитации | [README](lab%203.2/README.md) |

## Получение проекта

```bash
git clone https://github.com/levsulimov/practicum_prog3.git
cd practicum_prog3
```

## Быстрый запуск

Требуется Python 3.9 или выше с рабочим Tcl/Tk. Сторонние Python-пакеты не нужны.

Windows:

```powershell
py -3 "lab 3.1/starfield.py"
py -3 "lab 3.2/fireworks.py"
```

macOS / Linux:

```bash
python3 "lab 3.1/starfield.py"
python3 "lab 3.2/fireworks.py"
```

Каждая команда запускает отдельную программу. Подробные инструкции, управление и описание реализации находятся в README соответствующей работы.
